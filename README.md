# БОМЖ КОМБАТ — Башня Двора

Браузерный аркадный файтинг на движке с процедурными конечностями (цикл ходьбы, старт/актив/восстановление ударов, хитстоп, ИИ, частицы, тач, звук).

## Гибридная графика

- **В бою** тела бойцов — **процедурные** (limb-drawn), палитры подогнаны под наш каст (оранжевая шапка и оливковый пуховик у героя «ТЫ», синий худи у Валеры Картона и т.д.). Bitmap walk-спрайты в бой **не** подставляются — чтобы ноги ходили.
- **UI / меню / башня / VS**: наши ассеты — `player-portrait.webp`, `enemy-portrait.webp` (с оттенком палитры), `player-idle.webp` / `enemy-idle.webp`, `arena-yard-bg.webp`, пропы (мусор, тележка, голубь, бутылка, картон), логотип.

## Как открыть

1. Откройте `dist/index.html` в Chrome / Firefox / Edge (сборка singlefile + встроенные картинки).
2. Или распакуйте `bomzh-kombat.zip` и откройте `index.html`.
3. Из исходников: установите зависимости и выполните production-сборку Vite в этой папке.

Сеть на рантайме не нужна (шрифты Google — опционально).

## Кампания

Новая игра → Башня Двора (8 ступеней) → бой. Продолжить: `localStorage` ключ `bomzhKombatCampaign` (`stage`, `score`, `completed`).

Герой: **ТЫ** (Бомж Герой).  
Соперники: Валера Картон, Дядя Вова, Крыс, Бабка Зина, Санька Тележка, Гоша Голубь, Митя Скипидар, Король Подъезда.

## Управление

A/D — ходить · W — прыжок · S — присед · J — удар · K — нога · L — блок · U — спец / добить · P/Esc — пауза.

После нокаута: **ДОБЕЙ!** → спец = **ОТКЛЮЧКА** (без чужих trademark-слоганов).

Это самостоятельная игра, не связанная с чужими франшизами.
